This is a starter app which is embedded in the Komponentkassen
repository. The purpose of this starter app is primarily to be a place
to test and demonstrate the Komponentkassen Electric Clojure 3 library
and secondarily to be a starter app that developers wanting to use
Electric Clojure and Komponentkassen can use to get started quickly
and easily.

Although you are technically working in the starter app project, you
should ALWAYS think of it as working in the Komponentkassen as a
whole. 

The root of the Komponentkassen repository is at ../

The starter app is in the ./electric3-starterapp relative to the
Komponentkassen repository

We want
you to help us develop the Komponentkassen library as a whole and
incidentally the way you do that is to use it the starter app.

For example, if you are asked to create a new component, always do
that in ../src/com/itonomi/komponentkassen/<...>.cljc
